 # Endless Runner

A work-in-progress endless runner game built with Godot.


## Reminder

DO NOT PUSH TO MAIN BRANCH
CHECK YOUR CURRENT BRANCH BEFORE COMMITING
USE MODULAR CODE. CHECK GAME MANAGER, USE GETTERS AND SETTERS WHEREVER REQUIRED
USE SIGNALS FOR EVENTS

## Progress

- Platform spawning is implemented.
- Coin logic is implemented.
- UI Coin score implemented.
- Game over logic implemented
- Player lateral movement and jump implemented. Check Project-Settings > Input Map
